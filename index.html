Google Sheets Sync
Sync portfolio, live prices, history & transactions across devices
Connect your own Google Sheet

1. Open sheets.new to create a Google Sheet.
2. Click Extensions → Apps Script, delete the placeholder code, and paste the contents of appsscript.gs (in this folder). The script auto-creates Holdings and Settings tabs.
3. Deploy → New deployment → Web app. Set Execute as: Me and Who has access: Anyone.
4. Copy the Web App URL into config.json (gsUrl), then reload this page.
★ Re-deploying? Manage deployments → Edit → New version — the URL stays the same.
